# SubVost VPN

[Скачать приложение](https://pystoyplayer.github.io/subvost-vpn/) · [История обновлений](https://github.com/PystoyPlayer/subvost-vpn/releases)

На сайте выберите систему и процессор — он покажет подходящий файл.

## macOS

Apple Silicon и Intel. Основная версия — macOS 13 и новее; Legacy — macOS 11–12. Сборки пока не имеют нотариального заверения Apple; подсказки по установке доступны на сайте.

## Linux

x86_64 и ARM64: DEB для Ubuntu/Debian, RPM, Arch Linux, AppImage и архив. Нужны glibc 2.35 или новее и systemd; Ubuntu 22.04 и новее соответствует этим требованиям. Поддержка каждого дистрибутива и окружения рабочего стола не гарантируется.

## Windows — предварительная версия

x64, ARM64 и x86. Распакуйте архив и запустите приложение. Системный компонент устанавливается в настройках с подтверждением администратора. Проверка исправлений на реальном Windows-компьютере ещё требуется.

## Обновление

Перед установкой отключите VPN и закройте приложение. Подписка сохраняется. На Windows после смены версии обновите также системный компонент в настройках. Не включайте одновременно два VPN в режиме TUN.

Исходный код приложения в этом репозитории не размещается.
