Приложения SubVost VPN: загрузки и история обновлений. Исходный код в этом репозитории не размещается.

[Скачать приложение и посмотреть изменения](https://github.com/PystoyPlayer/subvost-vpn/releases)

## macOS

Выберите **arm64** для Mac с Apple Silicon (M1 и новее) или **x86_64** для Intel. Текущие сборки требуют macOS 13 или новее.

Откройте DMG, перенесите SubVost VPN в «Программы» и добавьте ссылку подписки из бота. Тестовые сборки пока не имеют notarization Apple — это ограничение отдельно отмечается в релизе.
