# SubVost VPN

[Скачать приложение](https://download.subvost.fun/) · [Резервный сайт](https://pystoyplayer.github.io/subvost-vpn/) · [История обновлений](https://github.com/PystoyPlayer/subvost-vpn/releases)

На сайте выберите систему и процессор — он покажет подходящий файл.

## macOS

Apple Silicon и Intel. Версия 1.0.2 для macOS 13 и новее подписана Developer ID и нотариально заверена Apple. При переходе со старой версии отключите VPN, закройте приложение и установите новый DMG вручную; при первом подключении разрешите системный VPN в окне macOS. С версии 1.0.0 (66) также нужно обновиться вручную: проверка обновлений в ней не запускалась. Legacy для macOS 11–12 остаётся отдельной прежней сборкой без нотариального заверения; её подсказки по установке доступны на сайте.

## Linux

x86_64 и ARM64: DEB для Ubuntu/Debian, RPM, Arch Linux, AppImage и архив. Нужны glibc 2.35 или новее и systemd; Ubuntu 22.04 и новее соответствует этим требованиям. Поддержка каждого дистрибутива и окружения рабочего стола не гарантируется.

## Windows

x64, ARM64 и x86. Запустите EXE-установщик: приложение появится в меню «Пуск» и на рабочем столе. Системный компонент устанавливается в настройках с подтверждением администратора. Обновление через приложение использует установщик для вашего процессора, а не ZIP-архив.

## Обновление

Перед установкой отключите VPN и закройте приложение. На Windows после смены версии обновите также системный компонент в настройках. Не включайте одновременно два VPN в режиме TUN.

Android 1.0.0 использует новый ключ подписи: для перехода со старых сборок сначала убедитесь, что ссылка подписки доступна в боте, затем удалите прежнее приложение, установите новое и добавьте ссылку заново. Локальные настройки не сохраняются при удалении. Если лимит устройств заполнен, удалите прежнее устройство через раздел управления устройствами бота. На остальных платформах обычное обновление не требует удаления приложения.

Исходный код приложения в этом репозитории не размещается.
